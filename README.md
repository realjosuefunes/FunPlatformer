This game is inspired by many platformer games, mainly Mario. I created this game as a part of a college class, MM/AN 40A Introduction To Game Design at Berkeley College, Spring 2026. The title of this game is Treacherous Climb (cool I know).  I also created this in hopes to share my creativity and the hard work of the friends we made along the way. Some design choices that inspired the awy this game looks is games like Omori and a little bit of Minecraft.
The main selling points of this game is the challenge it gives players and the main feel I want players to have when playing this game is kind of like in a dreamy place, where nothing makes sense.
